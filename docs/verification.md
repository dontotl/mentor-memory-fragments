# 기억의 조각 MVP 검증 기록

검증일: 2026-09-14. 실행 장비: macOS / Apple M1 Pro 8코어 / RAM 16GB. 앱: `memory-app/`. 가상 사진·가상 텍스트·합성 음성만 사용했습니다. 실제 어르신 인터뷰 데이터는 사용하지 않았습니다.

## 현재 검증 결과

| 항목 | 결과와 범위 |
|---|---|
| Next.js 프로덕션 빌드 | 통과. 8개 UI 경로, 동적 인터뷰/API, manifest 생성 |
| TypeScript | `npm run typecheck` 통과 |
| Node 테스트 | `npm test` 10/10 통과: SQLite 영속성·소유권·수정·중복·출처·요청 크기·CSRF·공급자 계약·분할 TTS·Qwen 출력 검증 |
| Python 경계 테스트 | 9/9 통과: 미설치·잘못된 모델·과대/빈 입력·동시 추론·교차 출처·디스크 부족 |
| Playwright 텍스트 E2E | 프로덕션 앱에서 통과, pageerror 0개 |
| Playwright 녹음 수명주기 | 가상 마이크 + mock STT/TTS 응답으로 통과. 실제 음성 정확도 검증과 구분 |
| 실제 로컬 음성 | Qwen3-TTS Sohee 생성 WAV → faster-whisper small 한국어 전사 성공 |
| 외부 유료 API | 계약 fixture만 검증. 실제 API 키·유료 호출 없이 수행 |

텍스트 E2E는 가상 사진 선택과 별도의 multipart 파일 업로드, 동의, 글 답변, 엽서 저장·PNG 다운로드, 추가 인터뷰, 회고록 생성, 원문 수정 후 미저장 초안 보존, 재생성·승인·새로고침 복구, 다크 설정 저장, 상단 콤보·하단 홈 링크, 320/390px 가로 넘침, 데스크톱 미리보기, 보관함 삭제를 확인합니다. 질문 생성은 이 테스트의 새 게스트 설정에만 연결 실패 주소를 지정해 안내 모드로 고정했습니다. 실제 LLM 추론 성공을 이 결과로 주장하지 않습니다.

녹음 수명주기 테스트는 Chromium 가상 마이크를 사용합니다. 생각하기 시 track.enabled=false, 재개 시 true, 수동 완료 후 track 종료, 전사 후 별도 확인 전에는 DB에 턴이 저장되지 않음, 인터뷰 설정 스냅샷 ID 전달, 질문 재생 중단을 확인했습니다. 자동재생 제한을 해제한 테스트 브라우저이므로 실제 iPhone Safari의 하드웨어·권한·자동재생 동작은 추가 수동 확인 대상입니다.

재현 스크립트: `memory-app/tests/e2e_demo.py`, `memory-app/tests/e2e_audio.py`. 스크린샷과 PNG는 git 제외 `memory-app/test-results/`. 테스트가 만든 인터뷰와 사진만 종료 시 삭제합니다.

## 실제 CPU 음성 측정

faster-whisper small CPU int8, Qwen3-TTS 12Hz 0.6B CustomVoice Korean/Sohee CPU float32, CPU 추론 스레드 4개. 동시 추론 1개.

- 입력: “봄에 가족과 소풍을 갔어요. 어머니가 싸 주신 김밥을 먹었어요.”
- 생성: 24kHz WAV, 8.24초.
- TTS: 서버 41.23초 / 호출 wall time 41.26초.
- STT: 2.517초.
- 전사: “봄의 가족과 소풍을 갔어요. 어머니가 싸주신 김밥을 먹었어요.” — `에→의` 오류 및 띄어쓰기 차이.

한 번의 가상 문장 왕복 측정이며 p50/p95, 어르신 음성 정확도, 일반 x86 서버 성능으로 일반화하지 않습니다. 원기획의 1.5초/3초 지연 목표는 달성하지 못했습니다. GPU 없는 현재 구성은 한국어 로컬 기능 검증과 느린 낭독에는 사용할 수 있으나 즉각적인 음성 대화용이라고 권장할 수 없습니다. 설정의 외부 API 선택은 지연 대안이지만 실제 공급자별 지연·가격·개인정보 조건을 별도 확인해야 합니다.

원본 측정 파일은 git 제외 `memory-app/models/smoke/report.json`, `synthetic-sohee.wav`입니다. 앱은 녹음 구간 종료 후 전사하며 실시간 부분 자막이 아니고, TTS는 전체 WAV 생성 후 전달합니다. 취소는 늦은 재생을 막지만 이미 진행 중인 CPU 추론을 선점 종료하지 않습니다.

`HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1`로 재시작하여 두 모델 ready를 확인한 뒤 다시 생성·전사했습니다. 두 번째 WAV는 7.60초/24kHz, TTS 42.229초(서버)/42.258초(wall), STT 2.711초였고 입력 단어를 올바르게 전사했습니다. 실제 휴대폰 음성 검증은 아닙니다. 상세 모델 revision과 두 실행 결과는 `memory-app/speech/README.md`에 기록했습니다.

## 로컬 언어 모델 검증

Qwen3 4B Q4_K_M을 로컬 Ollama에 내려받았습니다. 기본 non-thinking 호출은 이 환경에서 추론 과정이 최종 답변에 섞이고 짧은 토큰 제한에서 끝나지 않는 문제가 있어, Qwen3에 한해 thinking 모드·1024 토큰·45초 상한으로 분리했습니다. `thinking` 필드는 읽거나 UI에 보내지 않고 검증된 최종 `content`만 사용합니다.

실제 가상 입력 검증에서 질문은 26.793초 후 형식 검증에 따른 안내 질문으로 전환됐고, 회고록은 16.135초 후 `source:ollama`로 원문 그대로와 출처 revision을 반환했습니다. 따라서 실제 LLM 회고록 경로는 확인했지만 질문이 항상 성공한다거나 즉시 응답한다고 보장하지 않습니다. 검증 후 LLM 메모리를 해제했고 모델 파일은 유지했습니다.

## 독립 검토 및 수정

별도 검증 에이전트의 두 차례 읽기 전용 검토에서 다음 문제를 찾아 구현 담당자가 수정했습니다.

- 기존 인터뷰가 현재 외부 API 설정을 잘못 사용하는 문제 → STT/TTS 요청에 인터뷰 ID 전달.
- 긴 회고록이 Python 500자 제한을 넘는 문제 → 450자 이하 순차 생성/재생.
- 재시도 중복 저장 및 늦은 전사 덮어쓰기 → request ID 유지, 세대 번호·취소, 처리 중 입력 잠금.
- API→로컬 설정 전환 시 숨겨진 잘못된 URL → 모드별 기본값 복구.
- 새로고침 질문·출처 손실 → 저장된 질문/공급자 표시.
- 미저장 회고록 초안 손실 → 원문 수정과 초안 편집 상태 분리, 저장 중 편집 잠금.
- 사용자 편집 후 문단 출처 오표시 → 현재 문단이 아닌 원본 초안 구성 순서/revision임을 명시.
- 실제 브라우저 동일 출처 요청 403 → Next 내부 localhost 정규화와 실제 Host 분리, 악성 Origin 403 회귀 검증.

UI·API·저장소·음성 공급자·녹음 상태를 별도 모듈로 분리하고 포맷을 통일했습니다. 키는 서버 SQLite의 암호화된 설정에 저장하고 클라이언트에는 hasKey만 반환합니다. 사진과 DB는 로컬 파일시스템을 사용하며 Object Storage·배포·유료 이미지 API 호출을 하지 않았습니다.

## 환경 문제와 운영 제한

초기 디스크 부족으로 설치가 실패했으나 공간 확보 후 모델 설치를 재개했습니다. 이번 작업에서 만든 실패 uv 캐시만 정리했고 기존 사용자 파일을 삭제하지 않았습니다.

공식 npm 레지스트리 연결은 회사 보안 게이트웨이의 미신뢰 CA로 실패했습니다. TLS 검증을 유지한 채 설치 명령에만 `https://registry.npmmirror.com`을 지정했습니다. 전역 레지스트리·인증서 검증 설정은 바꾸지 않았습니다. lockfile에 설치 출처와 integrity가 남습니다.

개발 파일 감시 한도 오류는 `WATCHPACK_POLLING=true` 실행으로 우회했습니다. 최종 E2E는 파일 감시가 없는 `npm run build` + `npm start` 프로덕션 앱에서 수행했습니다.

계정·가족 공유·기기 간 복구·인터넷 배포는 범위 밖입니다. 게스트 쿠키를 잃으면 기존 기록 접근도 잃을 수 있습니다. 실제 iPhone 설치/마이크, 실제 외부 음성·이미지 API 연결, 다양한 한국어 발화 품질·장시간 성능은 별도 검증이 필요합니다.
