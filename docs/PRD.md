# 기억의 조각 — 제품 요구사항 정의서 (PRD)

버전 1.0 · 2026-09-15 · 로컬 우선 교육·멘토링 MVP

이 문서는 제품의 목적, 사용자 여정, 구현된 요구사항, 기술적 선택, 검증 범위와 후속 과제를 정의한다. 실행 방법은 저장소 README, 상세 음성 설치 방법은 앱의 speech/README를 따른다.

## 1. 제품 목적과 대상 사용자

**사진 한 장에서 시작해 사용자가 확인한 말을 추억 엽서로 남기고, 원할 때만 대화를 이어 회고록을 완성한다.**

주 사용자는 사진을 보며 자신의 기억을 말로 남기고 싶은 60~70대 사용자다. 가족·보조자는 초기 실행과 기기 사용을 돕고, 멘토·개발자는 가상 시나리오로 제품 흐름과 구현 원리를 확인한다.

해결할 문제:

- 긴 글 작성 부담 때문에 기억을 기록하기 어렵다.
- 짧은 침묵을 답변 종료로 오인하면 사용자가 충분히 생각할 수 없다.
- AI가 사진의 시대·관계·장소를 추정하거나 원문을 각색하면 실제 기억과 구분하기 어렵다.
- 음성 인식 오류를 확인 없이 저장하거나 외부로 전송하면 신뢰와 통제권을 잃는다.

핵심 원칙은 짧게 시작하기, 기다려 주기, 사용자 확인 후 저장하기, 사실을 새로 만들지 않기, 데이터 처리 위치를 명확히 알리기다.

## 2. MVP 범위

포함 기능:

- 실제 사진 업로드 또는 가상 샘플 사진으로 인터뷰 시작.
- 한국어 음성 입력과 전사 수정·확인, 같은 흐름으로 완주하는 텍스트 입력.
- 첫 답변으로 엽서 작성·편집·저장·PNG 다운로드.
- 사용자가 선택한 추가 인터뷰와 원문 기반 회고록 작성·편집·승인·낭독.
- 로컬 저장, 원문·수정 이력 보존, 보관함 열기·삭제.
- 로컬 STT/TTS 기본 설정과 각각의 선택적 외부 API 연동.
- 모델 다운로드·준비 상태, 테마·큰글씨·묵음 시간 설정.
- 가상 사진과 대본을 사용하는 미리보기, 아키텍처와 기술 고려사항을 설명하는 소개 페이지.

범위 밖: 가족 계정·페어링, 기기 간 복구·공유, 인생 연대기, 출판, 음성 복제, 실시간 전이중 음성 대화, 완전 오프라인 인터뷰, 다중 서버 운영과 인터넷 서비스 배포.

## 3. 핵심 사용자 여정

1. **사진 선택과 동의:** 처리 안내를 읽고 사진을 업로드하거나 가상 샘플을 선택한다.
2. **첫 질문:** 사진 속 인물 관계·연도·장소를 사실로 추정하지 않는 질문을 받는다.
3. **답변과 확인:** 음성 또는 글로 답한다. 전사된 글을 수정하고 별도로 확인·전송한다.
4. **첫 결과:** 확인한 이야기로 엽서를 보고 수정·저장·다운로드한다. 여기서 끝내도 된다.
5. **선택적 이어 말하기:** 원하면 같은 인터뷰에서 몇 차례 더 답한다.
6. **회고록:** 원문과 초안 구성 출처를 확인하고 편집·승인한다. 이후 보관함에서 다시 연다.

미리보기는 AI 생성 가상 사진과 사용자가 선택한 샘플 대본으로 진행한다. 실제 가족 사진이나 기존 사용자의 기록을 장식·시연 자료로 사용하지 않는다. 텍스트 데모는 실제 API와 SQLite 저장 흐름을 사용하며, 모델이 없으면 안내 질문 모드임을 표시한다.

## 4. 기능 요구사항과 수용 조건

| ID | 요구사항 | 수용 조건 |
|---|---|---|
| F01 | 사진으로 시작 | 업로드·가상 샘플 모두 처리 안내와 동의를 거쳐 인터뷰를 생성한다. |
| F02 | 한국어 답변 | 음성과 글 입력을 제공하고, 전사 결과를 사용자가 고친 뒤 저장한다. |
| F03 | 생각할 시간 | 묵음 3/5/7초(기본 5초), 생각하기·재개·수동 완료·취소를 제공한다. |
| F04 | 추억 엽서 | 첫 확정 답변으로 결과를 표시하고 편집·저장·PNG 다운로드가 가능하다. |
| F05 | 회고록 | 확인된 원문을 바탕으로 초안을 만들고, 출처·수정 이력·승인 상태를 구분한다. |
| F06 | 보관함 | 자신의 기록만 조회·열기·삭제하며 다른 게스트의 데이터에 접근할 수 없다. |
| F07 | 음성 공급자 | STT/TTS 각각 로컬 또는 API를 선택·저장·테스트하며 키는 화면에 재노출하지 않는다. |
| F08 | 모델 관리 | missing/downloading/ready/error를 구분하고 실제 런타임 로드 성공 후 ready로 표시한다. |
| F09 | 모바일 탐색 | 하단 탭, 상단 화면 선택, 설정, 뒤로가기가 동작하며 작은 화면에서도 읽을 수 있다. |
| F10 | 실패 대응 | 전사·생성·낭독 실패를 알리고, 텍스트 입력·재시도·안내 모드 등 가능한 선택을 제공한다. |
| F11 | PWA | 설치 안내·manifest를 제공하고, 서버 연결이 없을 때 공개 오프라인 안내를 표시한다. |
| F12 | 제품 소개 | 아키텍처·처리 과정·기술 선택·데이터 경계·제약·PRD·데모를 같은 페이지에서 확인한다. |

주요 화면은 `/`, `/start`, `/interview/[id]`, `/postcard/[id]`, `/memoir/[id]`, `/library`, `/preview`, `/settings`이며 소개 페이지는 `/project.html`이다.

한국어 가독성, 충분한 터치 영역, 큰글씨, 명확한 처리 상태, 키보드 포커스, 라이트/다크, 모션 감소를 우선한다. 브랜드의 종이색과 초록 계열을 유지한다. 설치 가능한 웹 앱인 PWA이며 React Native 네이티브 바이너리는 아니다.

## 5. 실행 구조와 공통 API 계약

| 구성 요소 | 책임 |
|---|---|
| Next.js PWA / React / Konsta iOS | 사진·마이크 입력, 전사 검토, 탐색, 엽서 Canvas, 회고록 편집 |
| Next.js Node API | 게스트 세션, 소유권, 설정, 원문 저장, 공급자 호출 |
| SQLite WAL + 로컬 파일 | 인터뷰·수정 이력·설정, 사진·이미지 보관 |
| Python FastAPI 음성 서비스 | faster-whisper small CPU int8 / Qwen3-TTS 0.6B CustomVoice 한국어 Sohee |
| Ollama qwen3:4b | 질문 및 원문 기반 회고록 구성, 실패 시 명시적 안내 모드 |
| 선택적 외부 API | 사용자 설정에 따른 STT/TTS, 명시적 GPT Image 생성 |

기본 포트는 앱 3000, 음성 서비스 8765, Ollama 11434이며 로컬 루프백을 사용한다. “로컬”은 연결된 서버에서의 추론을 뜻한다. 휴대폰 내부에서 모델이 실행되는 것은 아니다.

녹음 구간 전송 → 전사 반환 → 사용자 수정·확인 → 확정 턴 저장 → 다음 질문 생성 → 엽서 화면 표시 순서다. 텍스트 입력은 녹음·전사를 건너뛰고 확인·저장에 합류한다. 모델 응답 대기 중에는 저장 트랜잭션을 유지하지 않는다.

| API 영역 | 계약 |
|---|---|
| 설정·상태 | GET/PUT `/api/settings`, GET `/api/health` |
| 인터뷰 | GET/POST `/api/interviews`, GET/DELETE `/api/interviews/:id` |
| 답변·수정 | POST `/api/interviews/:id/turns`에 text/requestId, PATCH fragment에 수정 text |
| 결과물 | POST `/api/interviews/:id/postcard`, POST `/api/interviews/:id/memoir` |
| 음성 | POST `/api/stt` multipart audio, POST `/api/tts` text |
| 모델·이미지 | POST `/api/models/download`에 stt/tts 종류, POST `/api/image`에 prompt/interviewId |
| 미디어 | GET `/api/media/:id`, 소유권 확인 후 제공 |

오류는 JSON error로 반환한다. 설정 조회는 API 키 원문 대신 hasKey만 반환한다. 인터뷰 시작 시 공급자 설정을 스냅샷으로 보존한다. 구체적인 타입은 앱의 `src/lib/contracts.ts`가 정의한다.

## 6. 기술적 고려사항

| 주제 | 선택과 이유 | 제약 |
|---|---|---|
| 웹·모바일 | PWA로 웹 코드와 모바일 탐색을 공유 | 네이티브 앱이 아니며 실제 iPhone 권한·설치를 별도 확인해야 한다. |
| 음성 분리 | STT/TTS를 독립 교체해 로컬·API 선택 가능 | 음성-to-음성 단일 멀티모달 모델이나 실시간 부분 전사가 아니다. |
| CPU 추론 | Whisper small int8, Qwen3-TTS 0.6B, 동시 음성 추론 1개 | 작은 모델도 실시간 속도를 보장하지 않으며 RAM·디스크가 필요하다. |
| 확정 시점 | 녹음 종료와 답변 확인을 구분 | 묵음 감지는 사용자의 저장 승인과 다르다. |
| 긴 낭독 | 로컬 500자 한도에 맞춰 450자 이하 순차 호출 | 전체 WAV 완성 후 전달하며 문장 사이 대기가 있다. |
| 재시도·취소 | requestId 중복 방지와 세대 번호로 늦은 결과 무시 | 재생 중단이 서버 CPU 추론의 선점 종료는 아니다. |
| 저장 | SQLite WAL, 로컬 파일, 짧은 저장 트랜잭션 | 다중 서버 공유 저장소·고가용성 구성은 아니다. |
| 사실 보존 | 원문 ID 순서로 초안을 구성하고 수정 이력 유지 | 사용자 자유 편집 후 문단별 출처 정합성을 보장하지 않는다. |
| 설정 경계 | 시작 시 스냅샷, 서버에서만 키 사용 | 새 설정이 진행 중 인터뷰에 조용히 적용되지 않는다. |
| 장애 대응 | 시간 제한·출력 검증·안내 모드 | ready/연결됨은 품질·속도·모든 요청 성공의 보증이 아니다. |
| 로컬 보호 | 게스트 소유권, AES-GCM, 허용 호스트·Origin 검사 | 계정·기기 복구가 없고 서버와 키 동시 탈취까지 방어하지 않는다. |
| PWA 캐시 | 공개 오프라인 안내만 캐시 | 개인 사진·API는 캐시하지 않으며 서버 없이 인터뷰할 수 없다. |

GPT Image는 로컬 설치 모델이 아니라 선택적 외부 API다. 생성된 가상 샘플 파일만으로 기본 데모를 수행할 수 있다. 외부 음성·이미지 API로 자동 장애 전환하지 않는다.

## 7. 데이터 처리와 보안 요구사항

| 데이터 | 기본 처리·보관 | 외부 전송 조건 |
|---|---|---|
| 사진 | 로컬 media, 소유권 검사; 파일 자체는 비암호화 | 현재 원본 사진을 이미지 API로 자동 전송하지 않는다. |
| 녹음 | 전사 중 임시 처리, 서버 지속 보관 안 함 | STT API를 선택한 인터뷰 또는 명시적 연결 테스트 |
| 확인한 글·수정 이력 | 암호화된 SQLite 기록 | TTS API를 선택한 인터뷰에서 낭독 요청 시 |
| 삽화 설명 | 명시적 생성 입력, 결과는 로컬 저장 | GPT Image 생성 버튼 요청 시 |
| API 키 | 서버의 암호화 설정, 화면은 hasKey 표시 | 설정된 공급자의 인증 요청에만 사용 |

DB·미디어·로컬 암호화 키는 `memory-app/data/`에 생성되며 Git에서 제외한다. 백업은 서버 정상 종료 후 데이터와 키를 함께 보호해야 한다. 게스트 쿠키를 잃으면 이 백업만으로 새 브라우저의 소유권이 복구되지는 않는다.

키·개인 사진·음성·DB·모델은 공개 저장소나 이슈에 포함하지 않는다. 보관함 삭제는 해당 소유 기록과 미디어를 삭제한다. 현재 구성은 보안 인증이나 완전한 익명성을 보장하지 않는다.

## 8. 검증 범위와 성능 한계

현재 MVP의 자동 검사 항목은 원문 보존, 수정 이력, 중복 요청, 소유권 분리, 공급자 계약, 요청 경계, 긴 TTS 분할, 문서 생성과 동기화다. 브라우저에서는 가상 사진 업로드 → 글 답변 → 엽서 → 추가 인터뷰 → 회고록 승인·복구와 탐색·설정을 검사한다.

소개 페이지는 작은 화면·키보드·다크·모션 감소, 명시적 다이어그램 지연 로딩, 실패 안내, PRD 원문·다운로드 일치를 검사한다. 과거 390/768/1440px와 200% CSS 확대 검사가 실제 iPhone 설치나 브라우저 UI 확대 검증을 대신하지는 않는다.

2026-09-14 로컬 측정 조건: M1 Pro 8코어, RAM 16GB, CPU 음성 추론 4스레드. 가상의 동일 한국어 대본을 Sohee로 합성한 뒤 Whisper에 입력했다.

| 회차 | 합성 오디오 길이 | TTS 서버 처리 | STT 처리 |
|---|---|---|---|
| 1 | 8.24초 | 41.23초 | 2.517초 |
| 2 | 7.60초 | 42.229초 | 2.711초 |

첫 전사에서 ‘봄에’를 ‘봄의’로 인식했다. 합성 대본 두 번의 결과로 p50/p95, 실제 어르신 발화 정확도, 일반 x86 성능을 보장할 수 없다. 목표 지연 1.5초/3초를 달성한 구성으로 표시하지 않는다. 실제 질문 생성은 안내 모드로 전환된 사례가 있고, 회고록 원문 구성은 Ollama 경로가 확인됐다.

유료 API는 계약용 테스트와 실제 호출을 구분한다. 현재 공개 자료는 실제 유료 공급자 품질·지연 검증을 완료했다고 주장하지 않는다. 모델 다운로드 후 로컬 로드는 확인했지만 완전 오프라인 앱이라는 뜻은 아니다.

## 9. 출시 기준과 후속 과제

교육용 MVP의 수용 기준:

- 가상 사진과 텍스트만으로 핵심 여정을 완주할 수 있다.
- 사용자의 확인 없이 전사를 확정 저장하지 않는다.
- 원문·수정 이력·승인 상태가 새로고침 후 유지된다.
- 다른 게스트 기록 접근과 중복 저장을 방지한다.
- 로컬·외부 처리와 실패 상태, 미검증 범위를 사용자에게 알린다.
- 문서 빌드, 앱 테스트, 타입 검사, 프로덕션 빌드가 통과한다.

운영 서비스로 확대하기 전에는 실제 iPhone 설치·마이크·자동재생, 다양한 어르신 한국어 발화, 다중 사용자 부하, 계정·가족 공유·복구, HTTPS·배포·백업, 유료 API의 비용·개인정보 조건을 별도로 검증해야 한다.

성공 지표 후보는 첫 엽서 완주율, 전사 수정률, 저장 성공률, 오류 후 복귀율, 첫 음성 재생까지의 실제 대기 시간이다. 아직 실사용자 지표를 수집하거나 목표 달성을 입증한 단계는 아니다.
