# 기억의 조각 — 로컬 우선 MVP

실행 중인 앱: `http://127.0.0.1:3000` · 프로젝트 소개/계획서/데모 연결: `http://127.0.0.1:3000/project.html` · 아키텍처: `http://127.0.0.1:3000/architecture.html`.

소개 HTML은 `public/project.html`을 직접 열어도 읽을 수 있습니다. 데모 기능과 CSP로 외부 폰트 연결을 제한한 다이어그램은 앱 서버의 HTTP 링크를 사용하세요. 공개용 계획서·검증 MD는 `npm run guide:build`로 동기화하며 일반 빌드에도 포함됩니다.

사진 한 장 → 확인한 한마디 → 추억 엽서. 원하면 같은 인터뷰에서 이야기를 더 남기고, 원문 출처를 확인하며 회고록을 승인합니다. 가상 사진과 텍스트 대본으로 음성 모델 없이도 전체 흐름을 체험할 수 있습니다.

## 시작하기

Node.js 22와 Python 3.11을 사용합니다. 앱 폴더에서:

```sh
npm install
npm run dev
```

`http://127.0.0.1:3000`에서 열고 **미리보기** 또는 **사진으로 시작하기**를 선택합니다. 사진 처리 동의 후 **글로 답하기**로 진행하면 마이크·유료 API가 필요하지 않습니다. 샘플 사진은 GPT Image 엔진으로 생성한 가상의 인물이며 실제 가족 사진이 아닙니다.

음성 설치와 실제 검증 범위는 [speech/README.md](speech/README.md)에 있습니다. 기본 STT는 faster-whisper small CPU int8, TTS는 Qwen3-TTS 0.6B CustomVoice Korean/Sohee입니다. 모델 및 Python 환경을 위한 디스크 여유 8 GB 이상을 확보하세요.

```sh
sh scripts/setup-speech.sh
.venv/bin/python -m uvicorn speech.service:app --host 127.0.0.1 --port 8765
```

설정에서 모델을 다운로드하고 실제 `준비됨` 상태를 확인합니다. 질문 모델은 `http://127.0.0.1:11434`의 Ollama `qwen3:4b`를 사용합니다. 연결되지 않으면 명시적으로 안내 질문·원문 정리 모드가 작동합니다. 앱이 LLM 모델을 몰래 다운로드하거나 외부 API로 자동 전환하지 않습니다.

## 설정과 데이터

- STT/TTS는 각각 로컬 또는 OpenAI 호환 API를 선택합니다. API URL·모델·키·음성을 지정한 뒤 저장하고 테스트합니다. 공급자별 지원 형식은 다를 수 있습니다.
- 인터뷰 시작 시 음성 설정을 고정합니다. 변경된 설정은 새 인터뷰에 적용됩니다.
- GPT 이미지 생성은 로컬 설치 모델이 아닌 선택적 외부 API입니다. 키 설정과 명시적 생성 버튼 조작이 필요하며 비용이 발생할 수 있습니다. 원본 사진을 자동 전송하지 않습니다.
- SQLite·사진·암호화 키는 `data/` 로컬 디렉터리에 저장하고 git에서 제외합니다. Object Storage는 사용하지 않습니다. 백업할 때 DB와 로컬 키를 함께 보호해야 합니다.
- 브라우저의 HttpOnly 게스트 쿠키로 소유권을 구분합니다. 사용자 계정·가족 공유·기기 간 복구 기능은 아직 없습니다. 쿠키를 지우면 기존 기록에 접근할 수 없습니다.
- 원본 음성은 서버에 지속 저장하지 않습니다. 최초 확인한 글과 수정 이력은 보존하며 기록 삭제는 보관함에서 수행합니다.
- 인터넷에 공개하는 배포는 범위 밖입니다. 로컬 루프백에 바인딩합니다. 휴대폰에서 마이크를 쓰려면 별도 신뢰된 HTTPS 접속 환경이 필요합니다.

기본 허용 API 호스트는 `api.openai.com`입니다. 다른 OpenAI 호환 공급자는 `.env.example`을 참고해 `MEMORY_API_HOSTS`에 호스트 이름을 명시하고 서버를 재시작합니다. 임의 URL·리디렉션·로컬 주소로 비밀 키가 전송되는 것을 막기 위한 제한입니다.

로컬 백업은 앱과 음성 서버를 정상 종료한 상태에서 `data/` 전체(DB, WAL 관련 파일, 암호화 키, media)를 접근 제한된 별도 로컬 폴더에 복사합니다. 복원도 서버가 꺼진 상태에서 수행하며 기존 데이터를 덮어쓰기 전에 따로 보관합니다. 게스트 쿠키는 별도이므로 이 백업만으로 새 브라우저에 로그인하거나 소유권을 복구하지는 못합니다.

## 검증

```sh
npm test
npm run typecheck
npm run build
.venv/bin/python -m pytest tests/speech_test.py -q
```

브라우저 E2E는 `tests/e2e_demo.py`를 사용합니다. Playwright Python 및 Chromium을 별도로 설치하고 개발 서버를 먼저 실행합니다. 테스트가 만드는 기록은 가상 샘플이며 테스트 종료 시 해당 기록만 삭제합니다. 실제 마이크와 모델 품질 검증을 대신하지 않습니다.

## 구현 범위와 제한

PWA는 Next.js 웹 앱이며 React Native 바이너리 앱이 아닙니다. iPhone 홈 화면 추가와 모바일 UI를 지원합니다. 오프라인에서는 공개 안내 화면만 제공하고 사진·인터뷰·API 응답은 서비스 워커에 캐시하지 않습니다.

음성은 녹음 구간 종료 후 전사하고 확인한 글을 별도로 전송합니다. 묵음 3/5/7초, 생각하기·재개·취소를 지원하지만 실시간 부분 자막이나 전이중 음성 모델은 아닙니다. GPU 없는 서버에서 실시간 지연을 보장하지 않습니다. 실제 음성 성능은 모델 설치 후 측정해야 합니다.

회고록 초안은 사실을 추가하지 않도록 확인한 원문을 조합합니다. 사용자가 편집한 뒤 승인할 수 있으며, 원문 수정 후에는 출처가 갱신된 초안을 다시 만들어야 합니다.
