  1. 01 - 사진

    한 장으로 시작

    사진을 올리거나 가상 사진을 고르고, 데이터 처리에 동의합니다.

  2. 02 - 한마디

    말하거나 적기

    음성 전사를 고치거나 직접 글을 씁니다. 전사 완료와 답변 전송은 분리됩니다.

  3. 03 - 엽서

    여기서 끝내도 좋아요

    첫 답변으로 엽서를 저장하고 PNG로 내려받습니다.

  4. 04 - 회고록

    원문을 보며 완성

    선택한 추가 대화로 초안을 만들고 출처를 확인해 직접 승인합니다.

어디에서 무엇을 처리하나요?

휴대폰의 브라우저는 화면과 녹음을 맡고, 연결된 로컬 서버가 저장과 모델 추론을 맡습니다. 휴대폰 자체에서 모델을 실행하는 구조는 아닙니다.

전체 화면으로 열기 ↗

설명은 한국어입니다. 독립 뷰어의 고정 메뉴와 문서 언어 표시는 영어이며 테마는 뷰어에서 선택합니다.

기본은 연결된 로컬 서버

Next.js API(:3000)가 요청과 세션 소유권을 확인합니다. SQLite는 글·설정을, 로컬 media는 사진을 보관합니다. FastAPI(:8765)는 Whisper small int8 전사와 Qwen3-TTS 0.6B Sohee 낭독을, Ollama(:11434)는 Qwen3 4B 질문·원문 정리를 맡습니다.

외부 처리는 선택한 경우에만

STT/TTS 공급자는 인터뷰 시작 시 설정으로 고정합니다. GPT Image는 별도 생성 요청으로 사용합니다. 점선은 선택 경로이며 로컬 장애가 외부 API 자동 전환을 뜻하지 않습니다.

어떤 정보가 어디에 남나요?

기본 보관 장소는 로컬 서버입니다. 외부 공급자로 보내는 조건은 데이터마다 다릅니다.

데이터별 기본 처리와 외부 전송 조건
데이터기본 처리·보관외부 전송 조건
업로드 사진로컬 media, 소유권 확인 후 제공현재 원본 사진을 이미지 API에 자동 전송하지 않음
녹음 음성전사를 위한 임시 처리, 서버 지속 저장 안 함STT를 API로 선택한 인터뷰 또는 명시적 연결 테스트
확인한 글/수정 이력SQLite의 암호화된 인터뷰 기록TTS를 API로 선택한 인터뷰에서 낭독 요청 시
삽화 설명사용자가 입력한 설명으로 선택적 이미지 생성명시적 생성 버튼 요청 시 GPT Image API
API 키로컬 서버의 암호화 설정, 화면에는 hasKey만지정된 공급자 인증에만 사용

사진 파일 자체는 암호화하지 않습니다. 원음은 지속 보관하지 않지만 전사를 위한 임시 처리는 수행합니다. 이 설명은 법적 인증이나 완전한 익명성·보안 인증을 뜻하지 않습니다.

로컬 실행·접속 방법

프로젝트의 memory-app 폴더에서 실행합니다. 이미 실행 중이면 다시 켤 필요가 없습니다. 

cd memory-app
npm run build
npm start
# 앱: http://127.0.0.1:3000
# 소개: http://127.0.0.1:3000/project.html

음성 서비스는 별도 터미널에서 실행합니다. 설치된 모델만 쓰는 오프라인 모드입니다. 

cd memory-app
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python -m uvicorn speech.service:app --host 127.0.0.1 --port 8765

현재 루프백 접속 전용입니다. 휴대폰에서 실제 마이크를 쓰려면 신뢰되는 HTTPS 접속 환경을 별도로 구성해야 합니다. 게스트 쿠키를 지우면 기존 기록 접근을 잃을 수 있습니다.
